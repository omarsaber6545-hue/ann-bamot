# 🕌 Prayer Reminder Bot — بوت مواقيت الصلاة والأذكار

بوت ديسكورد احترافي ومصمم بأحدث تقنيات **Discord.js v14** ونظام **Slash Commands** فقط لتذكير الأعضاء بمواقيت الصلاة، أذكار الصباح والمساء، والأذكار المأثورة.

---

## 🌟 الميزات الرئيسية (Main Features)

- 🕋 **مواقيت الصلاة تلقائيًا (Cairo, Egypt):**
  - الفجر، الشروق، الظهر، العصر، المغرب، والعشاء.
  - إرسال إشعار لحظي في الدقيقة المحددة للأذان.
  - حساب التوقيت الهجري والميلادي والوقت الحالي في كل إشعار.
- 🌅 **أذكار الصباح والمساء:**
  - إرسال أذكار الصباح مباركة بعد صلاة الفجر (الساعة 06:30 صباحًا).
  - إرسال أذكار المساء بعد صلاة العصر/المغرب (الساعة 04:30 مساءً).
- 🌿 **أذكار عشوائية مأثورة:**
  - إرسال ذكر مأثور كل 1 ساعة تلقائيًا.
  - خوارزمية تضمن عدم تكرار نفس الذكر متتاليًا.
- ✨ **ميزات يوم الجمعة المبارك:**
  - التذكير بقراءة **سورة الكهف** والصلاة على النبي ﷺ (08:00 صباحًا).
  - التذكير بـ **ساعة الاستجابة** قبل غروب الشمس (05:00 مساءً).
- 💾 **قاعدة بيانات SQLite سريعة وآمنة:**
  - حفظ إعدادات كل سيرفر منفرداً (`better-sqlite3`).
- ⚡ **أوامر Slash تفاعلية بـ Discord.js v14:**
  - دعم كامل لـ UTF-8 واللغة العربية والتصميم الإسلامي باللون الأخضر الملكي `#1E824C`.

## 💻 قائمة الأوامر (Slash Commands)

| الأمر | الوصف |
| :--- | :--- |
| `/setup` | عرض لوحة تكوين السيرفر والقناة الحالية وحالة التذكيرات. |
| `/channel [target]` | اختيار القناة النصية التي تُرسل فيها الأذكار والمواقيت. |
| `/enable` | تفعيل خدمة التذكيرات الآلية بالسيرفر. |
| `/disable` | تعطيل خدمة التذكيرات الآلية بالسيرفر. |
| `/prayertimes` | عرض جدول مواقيت الصلاة الكامل لليوم (توقيت القاهرة ومصر). |
| `/nextprayer` | عرض الصلاة القادمة والوقت المتبقي بالعد التنازلي الحقيقي. |
| `/azkar` | إرسال ذكر مأثور عشوائي فوراً مع بيان فضله وأجره. |
| `/morning` | عرض وقراءة أذكار الصباح المباركة. |
| `/evening` | عرض وقراءة أذكار المساء المباركة. |
| `/today` | عرض الملخص الإسلامي اليومي (التاريخ، المواقيت، الحديث الشريف). |
| `/help` | عرض قائمة جميع الأوامر المتاحة. |

## 🚀 طريقة التشغيل (Setup & Run)

### 1. إعداد التوكن ومتغيرات البيئة:
افتَح ملف `.env` وضَع التوكن الخاص ببوتك وتعرف التطبيق (Client ID):

```env
DISCORD_TOKEN=ضع_التوكن_الخاص_ببوتينك_هنا
CLIENT_ID=ضع_معرف_التطبيق_Client_ID_هنا
```

### 2. تشغيل البوت:
```bash
node src/index.js
```

أو لتشغيله بنظام الإدارة المستمرة (PM2):
```bash
npm install -g pm2
pm2 start src/index.js --name "prayer-bot"
```
